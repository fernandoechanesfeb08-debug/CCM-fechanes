# Cloud Platform Comparison

## Checkpoint 3 – Major Platform Comparison

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | EC2 (Elastic Compute Cloud) | Azure Virtual Machines | Compute Engine |
| Storage Service | S3 (Simple Storage Service) | Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| Identity Service | IAM (Identity and Access Management) | Microsoft Entra ID | Cloud IAM |
| Primary Strength | Breadth of services, market maturity | Enterprise/Microsoft ecosystem integration | Data analytics, AI/ML, Kubernetes |
| Ideal Organizations | Startups to large enterprises needing the widest service catalog | Organizations already using Windows Server/Active Directory/Microsoft 365 | Data-driven and AI-focused organizations |
